# Release v4.20.0

**Data:** 2026-01-24
**Branch:** `release/v4.20.0`
**Status:** Wydany (Production 2026-01-24)

---

## Podsumowanie

Premium system typografii dla wszystkich stron CMS (Pages, Posts, Portfolio, Promotions) z fluid typography, polskimi zasadami typograficznymi i obsługą ciemnych teł zgodną z kolorami klienta.

---

## Features (Nowe funkcjonalności)

### Premium CMS Typography System
- Nowa klasa `.prose-paradocks` z fluid typography (clamp())
- Fluid type scale: nagłówki skalują się płynnie od 400px do 1280px viewport
- Plik `resources/css/prose-typography.css` z kompletnym systemem typografii

### Polish Typography Support
- Polskie cudzysłowy: „..." i ‚...'
- Automatyczne dzielenie wyrazów (hyphens: auto)
- Zapobieganie sierocom (text-wrap: pretty)

### Dark Theme Documentation
- Nowa dokumentacja `.claude/rules/dark-theme.md`
- Wyjaśnienie: "dark mode" = ciemne tło sekcji, NIE systemowy dark mode

---

## Fixes (Naprawy)

### Bug: Detekcja ciemnego tła w text-block.blade.php
- **Problem:** Kolory klienta (#00323B, #000000) nie były wykrywane jako ciemne
- **Przyczyna:** String matching (`str_contains('1f')`) zamiast kalkulacji jasności
- **Rozwiązanie:** Implementacja luminance calculation według WCAG
- **Efekt:** `prose-invert` włącza się poprawnie dla wszystkich ciemnych kolorów

---

## Improvements (Ulepszenia)

### WCAG 2.2 AA Compliance
- Line-height: 1.7 (wymóg: >= 1.5)
- Kontrast: 7.5:1 dla body text (wymóg: 4.5:1)
- Paragraph spacing: 1.5em

### Client Colors Integration
- Tekst na ciemnym tle: `#FFFFFF` (klient)
- Linki na ciemnym tle: `#0AB1EA` (klient)
- Obramowanie cytatów: `#0AB1EA` (klient)

### CMS Layouts Updated
- Wszystkie layouty używają teraz `prose-paradocks`
- Builder blocks (two_columns, three_columns) zaktualizowane
