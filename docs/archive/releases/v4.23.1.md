## Fixes (Naprawy)

### Deploy Script Stdin Bug (#174)
- **Problem:** `docker compose exec -T` czyta stdin, co w kontekscie SSH heredoc (`ssh ... 'bash -s' << 'EOF'`) konsumowalo pozostale linie skryptu. Bash tracil resztę heredoc i konczyl wykonywanie po pierwszym `exec`.
- **Skutek:** Kazdy deploy (staging i produkcja) pomijal: Redis wait, migracje, seedery, cache optimization, Filament optimize, Composer autoload, Horizon restart
- **Rozwiazanie:** Dodano `< /dev/null` do wszystkich wywolan `docker compose exec` w obu skryptach deploy
- **Dotyczy:** `ci-staging.yml`, `deploy-production.yml`

### Deploy Script Environment Variables (#172)
- **Problem:** `$REDIS_PASSWORD` nie byla dostepna w srodowisku shell uzytkownika `deploy` (zmienna jest tylko w Docker `.env`)
- **Rozwiazanie:** Dodano `set -a && source .env && set +a` na poczatku skryptow deploy
- **Dodatkowo:** Usunieto nieistniejacy `RolesAndPermissionsSeeder` z obu workflow
