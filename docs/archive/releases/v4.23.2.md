## Fixes (Naprawy)

### Missing MAIL_* env vars in app container (#177)
- **Problem:** Kontener `app` w `docker-compose.prod.yml` nie mial zadnych zmiennych `MAIL_*`. `MAIL_MAILER` defaultowal do `log` (z `config/mail.php`), przez co emaile wysylane synchronicznie z web requestow (np. przy tworzeniu rezerwacji) trafialy do pliku logu zamiast przez SMTP.
- **Skutek:** Emaile z kontekstu web request nie byly wysylane. Emaile z kolejki (Horizon) dzialaly poprawnie bo kontener `horizon` mial prawidlowe `MAIL_*` vars.
- **Rozwiazanie:** Dodano 8 zmiennych `MAIL_*` do sekcji `environment` kontenera `app`, identycznie jak w `horizon` i `scheduler`.
- **Dotyczy:** `docker-compose.prod.yml`
