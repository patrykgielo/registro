## Fixes (Naprawy)

### Null-safety for $errors in ios/input component (#180)
- **Problem:** Komponent `ios/input.blade.php` uzywal `$errors->has()` i `$errors->first()` bez sprawdzenia czy `$errors` nie jest null. Zmienna `$errors` jest ustawiana przez middleware `ShareErrorsFromSession`, ale moze byc niedostepna w niektorych kontekstach renderowania.
- **Skutek:** Strona `/register` rzucala blad `Call to a member function has() on null`.
- **Rozwiazanie:** Dodano PHP null-safe operator (`?->`) do obu wywolan `$errors` w linii 18-19.
- **Dotyczy:** `resources/views/components/ios/input.blade.php`
