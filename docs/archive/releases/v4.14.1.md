## Incydent 2026-01-21

**Problem:** Release v4.14.0 został wdrożony na produkcję bez explicit zgody użytkownika.

**Przebieg:**
1. Merge do main przeszedł pomyślnie
2. Tag v4.14.0 został utworzony automatycznie w ramach workflow
3. CI/CD wdrożył na produkcję
4. Deploy zakończył się sukcesem
5. Użytkownik zgłosił brak kontroli nad momentem deploy

**Root cause:** Brak reguły wymagającej zatrzymania i pytania przed tagowaniem.

**Rozwiązanie:** Dodanie ZASADY 0 jako najważniejszej reguły w self-improvement.md.

**Zapobieganie:** Reguła jest teraz udokumentowana i będzie stosowana w każdym przyszłym release.
