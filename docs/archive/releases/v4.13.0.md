## Nowe funkcjonalności

### 1. Gutenberg-like Block Styling (#90)

Refaktoryzacja wszystkich bloków CMS do spójnej struktury 3 tabów:

| Tab | Zawartość |
|-----|-----------|
| **Treść** | Pola specyficzne dla bloku (tekst, obrazy, etc.) |
| **Wygląd** | Tło + układ (uniwersalne dla wszystkich bloków) |
| **Zaawansowane** | CSS ID, klasy CSS |

**Nowe opcje tła (dla WSZYSTKICH bloków):**
- Kolor jednolity (color picker)
- Gradient (2 kolory + kierunek)
- Obraz z opcjonalną nakładką (overlay)
  - Wybór koloru nakładki
  - Slider przezroczystości (10-90%)

**Nowe opcje układu:**
- Toggle "Pełna szerokość"
- Selektor maksymalnej szerokości kontenera:
  - Wąski (640px)
  - Średni (768px)
  - Duży (1024px)
  - Standardowy (1280px) - domyślny
  - Szeroki (1536px)
  - Bardzo szeroki (1920px)
- Odstęp pionowy (sm/md/lg/xl)

**Nowe opcje zaawansowane:**
- CSS ID (dla kotwic i custom CSS)
- Dodatkowe klasy CSS

> **Uwaga:** Animacje wejścia zostały usunięte w #95 - funkcjonalność nie działała poprawnie.

**Pliki:**
```

~ app/Filament/Support/BuilderBlocks.php (refaktor)

```

### 2. Dark Theme dla Service Cards (#86)

Implementacja ciemnego motywu dla kart usług:

| Element | Kolor |
|---------|-------|
| Tło sekcji | `#00323B` (dark teal) |
| Karty/Tile | `#000000` (black) |
| Header | `#000000` (black) |
| Przyciski CTA | `#0AB1EA` (light blue) |
| Tekst | `#FFFFFF` (white) |
| Cienie | Kolorowy glow effect |

**Nowe klasy CSS:**
- `.bg-section-dark`
- `.service-card-dark`
- `.shadow-dark-glow`
- `.shadow-dark-glow-hover`
- `.btn-cta-dark`

**Komponent service-card:**
```blade
<x-ios.service-card :service="$service" variant="dark" />
```
Prop `variant`: `default` | `dark`

### 3. Selektor wariantu kart usług (#95)

Nowe pole w bloku "Siatka treści" pozwalające na ręczny wybór stylu kart usług:

| Opcja | Opis |
|-------|------|
| **Automatyczny (z tła)** | Wykrywa ciemne tło i automatycznie stosuje odpowiedni wariant |
| **Jasny** | Wymusza jasny styl kart (default) |
| **Ciemny** | Wymusza ciemny styl kart (dark) |

Pole widoczne tylko gdy typ treści = "Usługi".

## Bugfixy

### Resetowanie pól zależnych (#95)

**Problem:** Gdy użytkownik zmieniał typ treści (np. z "Usługi" na "Posty"), pole "Wybierz elementy" zachowywało poprzednie wartości (ID usług zamiast ID postów).

**Rozwiązanie:** Dodano `afterStateUpdated()` callback do pól z `->live()`:

| Blok | Pole | Resetowane pola |
|------|------|-----------------|
| `content_grid` | `content_type` | `content_items` |
| `hero` | `background_type` | `background_image`, `background_color` |
| `feature_list` | `layout` | `image` |

### Usunięcie niedziałających animacji (#95)

Usunięto pole "Animacja wejścia" z zakładki "Zaawansowane" - funkcjonalność oparta na `scroll-reveal` nie działała poprawnie z Livewire.
