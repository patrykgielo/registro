## Podsumowanie

Hotfix naprawiający krytyczny błąd 500 na produkcji spowodowany nieprawidłowym formatem zapisu logo w Settings oraz dodający zabezpieczenia security dla file uploads (SVG XSS, path traversal).

---

## Fixes (Naprawy)

### Naprawa błędu 500 przy wyświetlaniu logo

**Problem:**
```
TypeError: ltrim(): Argument #1 ($string) must be of type string, array given
at SettingsManager.php:315
```

**Root cause:** FileUpload w Filament dla non-Eloquent forms (Settings Pages) zapisuje pliki jako asocjacyjne tablice z UUID jako kluczem: `{"uuid-xxx": "path"}` zamiast string path.

**Rozwiązanie:**
- Dodano `extractFilePath()` używające `reset()` do bezpiecznej ekstrakcji ścieżki z różnych formatów (string, numeric array, associative array)
- Dodano `validateFilePath()` z walidacją path traversal, absolute paths, livewire-tmp

---

## Improvements (Ulepszenia)

### Zabezpieczenie SVG przed XSS

**Problem:** SVG może zawierać embedded JavaScript (`<script>` tags) - krytyczne zagrożenie XSS.

**Rozwiązanie:**
- Dodano pakiet `enshrined/svg-sanitize`
- Implementacja sanityzacji SVG w `saveUploadedFileUsing()` usuwająca:
  - `<script>` tags
  - Event handlers (onclick, onerror, etc.)
  - Remote references (zewnętrzne URL)
  - Inne potencjalnie niebezpieczne elementy

### Magic Bytes Validation

**Defense in depth:** Dodano walidację magic bytes dla obrazów rastrowych (PNG, JPEG, WebP) aby zapobiec MIME type spoofing.

### Path Traversal Prevention

Nowa metoda `validateFilePath()` w SettingsManager:
- Odrzuca ścieżki absolutne (`/etc/passwd`, `C:\`)
- Odrzuca path traversal (`../`, `..\\`)
- Odrzuca niesfinalizowane pliki (`livewire-tmp`)
- Weryfikuje istnienie pliku w storage

## Migracja

Brak migracji wymaganych. Fix jest backwards compatible.

**Opcjonalne:** Jeśli w bazie są nieprawidłowe wartości logo:
```bash
php artisan tinker --execute="
    \App\Models\Setting::where('key', 'header_logo')->update(['value' => json_encode([null])]);
    \App\Models\Setting::where('key', 'footer_logo')->update(['value' => json_encode([null])]);
"
```
