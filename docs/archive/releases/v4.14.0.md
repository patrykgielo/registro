## Nowe funkcjonalności

### 1. CTA Container Background

Nowa sekcja "Tło kontenera CTA" w bloku CTA Banner umożliwiająca:

**Dwuwarstwowy system tła:**
```
<section style="background: ...">        ← Tło sekcji (zewnętrzne)
  └─ <div class="rounded-3xl p-10"       ← Tło kontenera CTA (wewnętrzne)
         style="background: gradient...">
       └─ heading, buttons...
```

**Opcje tła kontenera:**
| Typ | Opis |
|-----|------|
| Brak | Kontener bez własnego tła (domyślne) |
| Kolor | Jednolity kolor (color picker) |
| Gradient | 2 kolory + kierunek |

**Opcje zaokrąglenia:**
- `lg` (0.5rem)
- `xl` (0.75rem)
- `2xl` (1rem)
- `3xl` (1.5rem) - domyślne

**Opcje padding:**
- `md` (2rem / 3rem na md:)
- `lg` (2.5rem / 4rem na md:) - domyślne
- `xl` (3rem / 5rem na md:)

**Auto kontrast tekstu:**
Automatyczne wykrywanie jasności tła kontenera i dostosowanie koloru tekstu.

**Pliki:**
```
+ app/Filament/Support/BlockStyling.php::ctaContainerSchema()
~ app/Filament/Support/BuilderBlocks.php (sekcja "Tło kontenera CTA")
~ resources/views/components/content-blocks/cta-banner.blade.php
```

### 2. Gradient Direction Fix

Naprawa błędu gdzie kierunki Tailwind były używane bezpośrednio w CSS `linear-gradient()`.

**Problem:**
```php
// ❌ BŁĘDNE - Tailwind w CSS
style="background: linear-gradient(to-r, #000, #fff);"
// Renders: linear-gradient(to-r, ...) - INVALID CSS!
```

**Rozwiązanie:**
```php
// ✅ POPRAWNE - Mapowanie do CSS
$cssDirection = match($direction) {
    'to-r' => 'to right',
    'to-l' => 'to left',
    'to-t' => 'to top',
    'to-b' => 'to bottom',
    'to-br' => 'to bottom right',
    'to-bl' => 'to bottom left',
    'to-tr' => 'to top right',
    'to-tl' => 'to top left',
};
style="background: linear-gradient({$cssDirection}, #000, #fff);"
```

**Plik:**
```
~ resources/views/components/blocks/partials/section-wrapper.blade.php
```

### 3. Tailwind Safelist

Dynamiczne klasy generowane w PHP `match()` nie są wykrywane przez Tailwind JIT.

**Problem:**
```php
// Tailwind JIT NIE widzi tych klas podczas buildu
$classes = match($padding) {
    'md' => 'p-8 md:p-12',
    'lg' => 'p-10 md:p-16',
    'xl' => 'p-12 md:p-20',
};
```

**Rozwiązanie - safelist w tailwind.config.js:**
```js
safelist: [
    'p-8', 'p-10', 'p-12',
    'md:p-12', 'md:p-16', 'md:p-20',
    'rounded-lg', 'rounded-xl', 'rounded-2xl', 'rounded-3xl',
],
```

**Pliki:**
```
~ tailwind.config.js
~ resources/css/app.css (komentarz dokumentujący)
```
