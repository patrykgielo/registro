# Release v4.26.0

**Data:** 2026-01-31
**Branch:** `release/v4.26.0`
**Status:** Wydany

## Podsumowanie

Konfigurowalny overlay hero na stronie pojedynczej uslugi. Zastapienie hardcoded gradientu (fioletowo-niebieskiego) dynamicznym overlayem z CMS.

---

## Features (Nowe funkcjonalnosci)

### Konfigurowalny overlay hero uslugi
- Nowe pola w panelu admin: kolor nakladki (ColorPicker) i przezroczystosc (Select 10-95%)
- Domyslnie: czarny (#000000), 85% opacity
- Konfiguracja per-usluga w sekcji "Zdjecie wyrozniajace"
- Zastepuje hardcoded gradient `from-blue-600 via-purple-600 to-indigo-700`

---

## Fixes (Naprawy)

### APP_URL bez portu w docker-compose lokalnym
- `docker-compose.yml` i `docker-compose.dev.yml` hardcodowaly `APP_URL=https://paradocks.local` bez portu 8444
- `Storage::url()` generowal URLe bez portu, co powodowalo `ERR_CONNECTION_REFUSED` na zdjeciach
- Naprawione: `APP_URL=https://paradocks.local:8444`

## Migracja

