- Slow tier = 9 classes (7 ServiceForm*, PanelWalkthroughTest, CatalogImportFormParityTest) tagged class-level `#[Group('slow')]`; list pinned in `tests/Unit/SlowGroupIsDeclaredTest.php` (exact set + typo'd group + method-level + dead `@group slow` docblock). Measured `--parallel`: fast (`--exclude-group=slow`) 54 s / 2613 tests, slow 254 s / 286, full 336 s / 2899. a+b==c verified by JUnit multiset. `--exclude-group` IS honoured by `artisan test --parallel`.
- **`--parallel` "N passed" is under-counted by exactly the tests that emit a PHPUnit 12 notice** (13 Przelewy24ServiceTest + 3 CartServiceTest + 2 ExportOrganizationDataJobTest = "mock without expectations"). Pest's parallel ResultPrinter counts only progress char `.` as passed; `N/D/R/W/I` print `!` and are dropped from "passed". Nothing is skipped: seq vs par JUnit are identical by (class,name). **Why:** a 18-test gap looked like lost coverage. **How to apply:** compare JUnit, never console counts, across modes.
- **Catalog-import parallel race: FIXED (review round).** `ImportCatalog` scratch root (`storage/app/tmp/catalog-import`) is real shared FS; `CatalogImportHardeningTest`/`Round3Test` assert on / plant stale dirs in it, and `removeStaleScratch()` of a sibling worker deletes them. Measured BEFORE: `artisan test --parallel --filter=CatalogImport` failed 3/5 runs; an 8-process shard stress (Catalog files spread over 8 phpunit processes, each with its own `TEST_TOKEN`) failed 4/5 rounds, in BOTH directions (Hardening "scratch cleaned up" and Round3 "stale scratch threshold" planted dir deleted). AFTER: 0/5 and 0/5. Fix = `CatalogImportConfig::scratchRoot()` (config `catalog_import.scratch_root`, absent in shipped config -> same `storage_path(...)` string) + `Tests\TestCase::setUp()` sets it to `...catalog-import-<ParallelTesting::token()>` when a token exists. Guard: `tests/Unit/CatalogImportScratchRootTest.php`. **How to apply:** any new test that asserts on / plants files in a real `storage_path()` dir needs the same per-token treatment; `Storage::fake()` already does it.
- PHPUnit 12 does NOT inherit `#[Group]` to subclasses (verified: `--group=slow --list-tests` lists parent only, `--exclude-group=slow` lists the child). `SlowGroupIsDeclaredTest` therefore fails on an unlisted subclass of a listed class, and on a test file whose declared class names don't include the file's basename (guard resolves by file name; helper classes in the same file are fine). Both mutation-verified.
- Tool quirk: `\` in my own Bash/heredoc commands is collapsed to one backslash; build PHP/Python text containing backslashes with `chr(92)` or the Write tool, not sed.
- Slow tier wall time is bounded by its biggest CLASS (ServiceFormEditCharacterizationTest ~250 s in one worker) because paratest parallelises per class; splitting that class or `--functional` is the lever (inference, not measured).
- Throwaway worktree runner: `docker run --rm --entrypoint sh -u laravel -v <worktree>:/var/www -w /var/www app-app -c '...'`. A fresh worktree needs `composer install` AND a copy of `public/build` (gitignored; without it ~14 Auth/Booking classes fail on the Vite manifest, which looks like regressions). Container php memory_limit is 256M (same as registro-app); a sequential run with those failures hit a memory fatal, clean run did not. No `time` in `sh` — use `date +%s`. WSL git is unreadable from Git Bash (`Not a git repository`) — run git via `wsl.exe -- sh -c`.
- Pint's `php_unit_method_casing` renames private helpers named `testXxx` to `test_xxx` — don't prefix helpers with `test`.
- Three old files carry an inert `@group skip` docblock (ServiceAreaWaitlistTest, BookingConfirmationSecurity{,Minimal}Test); they self-skip, harmless.

- 2026-11-24: the per-worker `catalog_import.scratch_root` override in `tests/TestCase.php` was DROPPED when merging develop: PR #315 fixed the same race first with `catalog_import.scratch_dir` + a per-TEST temp dir in `CatalogTestHelpers::setUpCatalog()` (stronger: also isolates test from test). One mechanism, theirs.
