# Section Wrapper Component - Usage Guide

## Overview

The `section-wrapper` component is a universal wrapper for all CMS content blocks that handles styling data generated by `BlockStyling.php` helper.

## Location

```
resources/views/components/blocks/partials/section-wrapper.blade.php
```

## Basic Usage

### Wrap Any Content Block

```blade
<x-blocks.partials.section-wrapper :data="$data">
    <!-- Your block content here -->
    <h2>My Content</h2>
    <p>This content will be wrapped with all styling options applied.</p>
</x-blocks.partials.section-wrapper>
```

### Example: Text Block with Styling

```blade
{{-- resources/views/components/content-blocks/text-block.blade.php --}}
@props(['data' => []])

<x-blocks.partials.section-wrapper :data="$data">
    <div class="prose prose-lg prose-primary max-w-none">
        {!! $data['content'] ?? '' !!}
    </div>
</x-blocks.partials.section-wrapper>
```

### Example: Feature List with Gradient Background

```blade
@props(['data' => []])

<x-blocks.partials.section-wrapper :data="$data">
    <div class="text-center mb-12">
        <h2 class="text-4xl font-bold">{{ $data['title'] ?? '' }}</h2>
    </div>
    
    <div class="grid grid-cols-1 md:grid-cols-3 gap-8">
        @foreach($data['features'] ?? [] as $feature)
            <div class="bg-white rounded-xl p-6 shadow-lg">
                <h3>{{ $feature['title'] }}</h3>
                <p>{{ $feature['description'] }}</p>
            </div>
        @endforeach
    </div>
</x-blocks.partials.section-wrapper>
```

## Supported Data Structure

The component expects a `$data` array with the following optional keys:

### Background Settings

```php
[
    'background_type' => 'none|solid|gradient|image',  // default: 'none'
    'background_color' => '#ffffff',                   // default: '#ffffff'
    'gradient_from' => '#0891b2',                      // default: '#0891b2'
    'gradient_to' => '#0e7490',                        // default: '#0e7490'
    'gradient_direction' => 'to-r',                    // default: 'to-r'
    'background_image' => 'path/to/image.jpg',         // default: null
    'background_overlay' => true,                      // default: false
    'overlay_color' => '#000000',                      // default: '#000000'
    'overlay_opacity' => '50',                         // default: '50' (string)
]
```

### Layout Settings

```php
[
    'full_width' => false,                             // default: false
    'container_max_width' => '7xl',                    // default: '7xl'
    'vertical_padding' => 'lg',                        // default: 'lg'
]
```

### Advanced Settings

```php
[
    'css_id' => 'custom-section',                      // default: null
    'css_classes' => 'custom-class another-class',     // default: ''
    'animation' => 'fade-in',                          // default: 'none'
]
```

## Configuration Options Reference

### background_type
- `none` - No background styling
- `solid` - Solid color background
- `gradient` - Linear gradient background
- `image` - Background image

### gradient_direction
- `to-r` - Left to right →
- `to-l` - Right to left ←
- `to-t` - Bottom to top ↑
- `to-b` - Top to bottom ↓
- `to-br` - Top-left to bottom-right ↘
- `to-bl` - Top-right to bottom-left ↙
- `to-tr` - Bottom-left to top-right ↗
- `to-tl` - Bottom-right to top-left ↖

### container_max_width
- `sm` - 640px
- `md` - 768px
- `lg` - 1024px
- `xl` - 1280px
- `2xl` - 1536px
- `7xl` - 1920px
- `full` - 100%

### vertical_padding
- `none` - No padding
- `sm` - 32px (2rem)
- `md` - 64px (4rem)
- `lg` - 96px (6rem)
- `xl` - 128px (8rem)

### animation
- `none` - No animation
- `fade-in` - Fade in on scroll
- `slide-up` - Slide up from bottom
- `zoom-in` - Zoom in from center

## Migrating Existing Blocks

### Before (without wrapper):

```blade
@props(['data' => []])

@php
    $bgClass = match($data['background_color'] ?? 'white') {
        'neutral-50' => 'bg-neutral-50',
        'primary-50' => 'bg-primary-50',
        default => 'bg-white',
    };
@endphp

<section class="py-24 px-4 {{ $bgClass }}">
    <div class="container mx-auto max-w-5xl">
        <!-- content -->
    </div>
</section>
```

### After (with wrapper):

```blade
@props(['data' => []])

<x-blocks.partials.section-wrapper :data="$data">
    <!-- content -->
</x-blocks.partials.section-wrapper>
```

All background, layout, and animation logic is now handled by the wrapper!

## Filament Integration

When creating Filament Builder blocks, use the BlockStyling helper:

```php
use App\Filament\Support\BlockStyling;

Forms\Components\Builder\Block::make('custom_block')
    ->schema([
        Forms\Components\TextInput::make('title')
            ->label('Title')
            ->required(),
        
        Forms\Components\RichEditor::make('content')
            ->label('Content'),
        
        // Add complete styling schema
        ...BlockStyling::completeSchema('pages/backgrounds'),
    ])
```

Or add individual schemas:

```php
->schema([
    // ... block fields ...
    
    Forms\Components\Fieldset::make('Background')
        ->schema(BlockStyling::backgroundSchema('pages/backgrounds'))
        ->columns(2),
    
    Forms\Components\Fieldset::make('Layout')
        ->schema(BlockStyling::layoutSchema())
        ->columns(2),
    
    Forms\Components\Fieldset::make('Advanced')
        ->schema(BlockStyling::advancedSchema())
        ->columns(2)
        ->collapsible()
        ->collapsed(),
])
```

## Features

### Storage URL Handling
- Uses `Storage::url()` for background images (respects `FILESYSTEM_DISK=public`)
- No manual `asset('storage/...')` path construction needed

### Overlay Support
- Automatic overlay rendering for image backgrounds
- Adjustable overlay color and opacity
- Content automatically positioned above overlay with `relative` class

### Responsive Container
- Full-width mode or constrained max-width
- Responsive padding: `px-4 sm:px-6 lg:px-8`

### Accessibility
- Semantic `<section>` element
- Proper CSS ID for anchor links
- Animation classes compatible with scroll reveal libraries

### Performance
- Inline styles only when needed
- No unnecessary DOM elements
- Minimal class bloat

## Notes

- The wrapper does NOT include any default content styling (fonts, colors, etc.)
- Inner content should handle its own typography and spacing
- Animation classes require JavaScript scroll reveal library (not included)
- Always test with `FILESYSTEM_DISK=public` in production
